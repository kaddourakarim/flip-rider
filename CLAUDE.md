# CLAUDE.md

## Context

I want to create a game for myself and my 5 year old son Léo that replicates this game https://elastomania.com/. I want the design to be simple just like this example.
I want the game to use only the arrows of my computer, back arrow to backflip and front arrow to front flip.
I want the website to look and feel https://elastomania.com/, with the same colors. 
I want the game to be gamified with points with a cup at the end of the race with your score. Your score would be a combination of how fast and how many back flips or front flips you have managed to do. 
I want my 5 year old to be able to play with it, so make the arrows not so sensitive. 
Create a product requirement document (PRD) for this project.
